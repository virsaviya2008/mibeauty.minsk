САЙТ САЛОНА КРАСОТЫ MIBEAUTY
=============================

Состав
------
index.html  — страница сайта
styles.css  — оформление
script.js   — калькулятор, квиз, отзывы, кнопки записи
img/        — фотографии

Сайт статический: не нужны база данных, PHP или CMS.
Загрузите все файлы (вместе с папкой img) на любой хостинг
в корневую папку сайта — и он заработает.


Онлайн-запись (DIKIDI)
----------------------
!!! СЕЙЧАС ЗАПИСЬ ВЫКЛЮЧЕНА: кнопки «Записаться» по нажатию ничего не делают.
!!! Чтобы включить — в начале script.js заменить
!!!   const DIKIDI = { enabled: false, ...
!!! на
!!!   const DIKIDI = { enabled: true, ...

После включения: на сайте нет форм записи, все кнопки «Записаться» открывают
онлайн-запись салона в DIKIDI (dikidi.net/mibeauty) в новой вкладке.

• Общие кнопки «Записаться» — экран «Выбрать услуги / Выбрать специалиста».
• «Записаться» у мастера — запись к этому мастеру.
• «Хочу так же», квиз, «Записаться на консультацию» — запись сразу
  на нужную услугу.
• Калькулятор с несколькими услугами — шаг выбора услуг в DIKIDI
  (DIKIDI не умеет отмечать несколько услуг по ссылке — клиент
  отмечает их сам, подсказка есть на сайте).

Настройки — в начале файла script.js:
• DIKIDI = { enabled: true, ... } — false временно выключает все кнопки записи;
• DIKIDI_MASTERS — номера мастеров в DIKIDI;
• DIKIDI_IDS — номера услуг в DIKIDI.


Что обновлять вручную
---------------------
Цены, услуги, отзывы и мастера на сайте не подтягиваются из DIKIDI
автоматически. Если в DIKIDI изменились цены или появились новые услуги:
• цены и длительность — массив SERVICES в script.js;
• номер новой услуги в DIKIDI — DIKIDI_IDS в script.js;
• новый мастер — блок «Наша команда» в index.html и DIKIDI_MASTERS в script.js.

Акция ноября на перманент (блок «Акции и новости» и старые цены
в калькуляторе) — после окончания акции нужно обновить или убрать.


После публикации
----------------
В index.html (в начале, строка с og:image) замените
img/brand-hd.jpg на полный адрес картинки, например:
https://ваш-домен.by/img/brand-hd.jpg
— тогда при отправке ссылки в мессенджерах будет показываться картинка.
